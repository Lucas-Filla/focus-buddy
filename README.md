# Focus Buddy
![Build](https://github.com/Lucas-Filla/focus-buddy/actions/workflows/build.yml/badge.svg)

A pixel-art desktop pet that sits on top of your screen and helps you stay focused.

Built in C++20 with raylib.

## Build (Windows)

1. Install Visual Studio 2026 with "Desktop development with C++".
2. Open this folder in Visual Studio (File → Open → Folder).
3. Select `focus_buddy.exe` as the startup item and press F5.
